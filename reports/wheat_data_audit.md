## Current CV implications

- **Block CV-E/CV-GE implementation until environment IDs are mapped.** For this crop, direct joins are incomplete; a mapping artifact must be versioned and validated against date/location metadata.
- Use CV-G as the primary protocol, but report coverage-stratified performance; single-environment materials cannot support a fully crossed G×E estimate.
- CV-E can use grouped environment folds, stratified by environment sample count and time/location where metadata permit.
- Genotype preprocessing and any phenotype-informed marker selection must be fitted inside each training fold; genotype-only ID/QC checks are reported separately.

## Open issues

- Environment ID is not a complete direct match between Environment.csv and Phenotypes.csv; resolve mapping before CV-E/CV-GE.
- Monomorphic markers should be removed inside each training fold or by a pre-declared genotype-only rule.
- Some materials occur in only one environment, so genotype holdout and G×E estimates are not equally supported for all materials.
